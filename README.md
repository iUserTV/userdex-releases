# UserDex

Instaladores e atualizações públicas do UserDex para Windows 64 bits.

## Download

[Abrir a versão mais recente](https://github.com/iUserTV/userdex-releases/releases/latest)

- **Instalador `.exe`**: baixe e execute para instalar o aplicativo.
- **ZIP com guias**: inclui o mesmo instalador e instruções em português, inglês e espanhol.
- **Arquivos `.sha256`**: permitem conferir se o download está íntegro.

O aceite dos riscos é obrigatório no primeiro uso. Instale somente se concordar com os termos apresentados no aplicativo.

## Atualizações

No UserDex, abra **Configurações → Atualizações** para verificar novas versões. O download e a instalação exigem sua ação e confirmação.

A primeira versão pública no GitHub é **1.0.0**. Quem usa uma versão de testes anterior deve instalar a versão pública manualmente, mesmo que a versão de testes tenha um número maior. Use a mesma pasta de instalação para conservar seus dados locais.

## Sobre este repositório

Este repositório distribui instaladores, guias e notas de versão. Não contém o código-fonte nem dados de contas ou sessões do desenvolvedor.

UserDex é um projeto de fã, sem vínculo oficial com o Poke Idle World.
